Privacy Policy — wire

wire is a desktop application with exactly one user: its author. It reads newsletters from that person's own Gmail mailbox and processes them on that person's own computer. This policy describes what it touches and what happens to it.

Who runs this

Göktuğ Yılmaz, an individual, reachable at goktugyilmaz01@gmail.com. wire is a personal project, not a product, service, or business. It is not offered to other users, and there is no sign-up.

What data wire accesses

With the gmail.readonly scope, and only that scope, wire reads:

  • messages sent by the specific sender addresses its user has configured — newsletter senders such as financial publications;
  • for each such message: the sender, subject, the date Gmail received it, and the message body;
  • the mailbox's own email address and message count, shown by its health check so the user can confirm the connection works.

wire does not request permission to send, delete, modify, or organise mail, and cannot do those things. It does not access contacts, Drive, Calendar, or any other Google service.

How the data is used

Messages are stored, converted to text, summarised, and indexed so that the user can search them and ask questions across them. Summarisation and question answering are performed by a language model running locally on the user's own computer. Nothing is used for advertising, profiling, or training any model.

Where the data is stored, and for how long

On the user's own computer, in that user's home directory, and nowhere else. There is no server, no cloud storage, no database operated by anyone, and no backup service. Data stays until the user deletes it; removing a newsletter feed deletes its stored messages and derived data, and deleting the application's data directory removes everything.

Who the data is shared with

No one. Email content is not transmitted to any third party, any external API, or any analytics or advertising service. The only network connections wire makes are to Google's own APIs to fetch the mail, and to a language model running on the same computer.

Limited Use disclosure

wire's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically: Google user data is used only to provide and improve the features described above; it is not transferred to others except as required by law; it is not used for advertising; it is not sold; and no human other than the mailbox's own owner reads it, except where required by law.

Security

  • Access is granted through Google OAuth. The user's Google password is never seen, typed into, or stored by wire.
  • The resulting refresh token is stored in the macOS Keychain of the computer that runs wire, not in a file or a configuration setting, and is never written to a log.
  • The permission granted is read-only, so a compromise of that computer could not be used to send or delete mail from the mailbox.

Withdrawing access and deleting data

  • Revoke the application's access at any time at Google Account → Third-party access, or from wire itself with wire auth --revoke, which also deletes the stored token.
  • Delete the stored mail by removing wire's data directory on the computer that runs it.

Children

wire is not directed at children and has no users other than its author.

Changes
