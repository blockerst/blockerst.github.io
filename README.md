# blockerst.github.io

Home and privacy pages for personal, single-user applications. Static HTML and one stylesheet —
no build step, no JavaScript, no third-party requests, no analytics.

These pages exist because Google requires an application home page and a privacy policy URL before
an OAuth app can leave "Testing" status (in Testing, refresh tokens expire every 7 days).

| page | URL |
|---|---|
| index | https://blockerst.github.io/ |
| wire — home | https://blockerst.github.io/wire/ |
| wire — privacy policy | https://blockerst.github.io/wire/privacy/ |

**This repository is public and must never contain anything else** — no application code, no
configuration, no credentials.
